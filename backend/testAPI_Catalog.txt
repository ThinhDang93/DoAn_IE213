================ CATALOG API TEST =================

Luu y chung:
- Thay cac ID mau bang ID that trong database.
- Cac API upload phim dung Body = Form-Data, field file phai la "File".


================ 1) QUAN LY PHIM =================

GET localhost:8080/api/QuanLyPhim/LayDanhSachPhim

GET localhost:8080/api/QuanLyPhim/LayThongTinPhim?MaPhim=<MOVIE_ID>

GET localhost:8080/api/QuanLyPhim/LayDanhSachBanner

POST localhost:8080/api/QuanLyPhim/ThemPhimUploadHinh
Body: Form-Data
- tenPhim: Dune: Part Two
- trailer: https://www.youtube.com/watch?v=Way9Dexny3w
- moTa: Phim khoa hoc vien tuong moi
- ngayKhoiChieu: 2026-11-01
- dangChieu: true
- sapChieu: false
- hot: true
- danhGia: 9
- File: <chon file anh>

POST localhost:8080/api/QuanLyPhim/CapNhatPhimUpload
Body: Form-Data
- maPhim: <MOVIE_ID>
- tenPhim: Dune: Part Two Updated
- trailer: https://www.youtube.com/watch?v=Way9Dexny3w
- moTa: Cap nhat mo ta
- ngayKhoiChieu: 2026-11-05
- dangChieu: true
- sapChieu: false
- hot: true
- danhGia: 10
- File: <chon file anh moi> (optional)

PUT localhost:8080/api/QuanLyPhim/CapNhatPhimUpload
Body: Form-Data (giong POST ben tren)

DELETE localhost:8080/api/QuanLyPhim/XoaPhim?MaPhim=<MOVIE_ID>
